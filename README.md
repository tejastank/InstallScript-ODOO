# [Odoo](https://www.odoo.com "Odoo's Homepage") TESTED SCRIPT FOR ODOO 18 INSTALL ON UBUNTU 24
 

## Installing Nginx
If you set the parameter ```INSTALL_NGINX``` to ```True``` you should also configure workers. Without workers you will probably get connection loss issues.  
## Installation procedure

##### 1. Download the script:
```
sudo wget https://raw.githubusercontent.com/tejastank/InstallScript-ODOO/18.0/odoo_install.sh
```
##### 2. Modify the parameters as you wish.
Open file and change parameters as requried, else connect hello@xamta.in
```
sudo chmod +x odoo_install.sh
```
##### 4. Execute the script:
```
sudo ./odoo_install.sh
```
